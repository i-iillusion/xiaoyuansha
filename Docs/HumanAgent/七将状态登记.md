# 七将状态与贤者复原登记

DEV-E01，2026-10-02。依据现行手册第6章、RESET-01、WIN-02及局部采纳记录。字段登记描述实现与归属，不新增玩法。新增武将字段须同时登记初值、写入/清除入口、寿命和复原归属。

## 武将自身与身份层

`Player.GENERAL_STATE_FIELDS`保存开局武将名、性别、朝向、觉醒/限定及神速状态；`capture_game_start_state`另存`general_max_hp = max_hp - identity_max_hp_bonus`。`restore_game_start_state`恢复武将字段及基础上限，再加**当前**身份层，恢复满体力。身份、公开状态、座位、其他角色、牌堆、已发生的回合/阶段历史不在快照内。

`identity_max_hp_bonus`初值0，只以差额调整上限，不隐含回复或扣除当前体力。H03负责模式初始化、身份转换与公开状态的整体接线；本批没有开放身份交换或奸雄，也没有改变已有开局加成。E01b用显式注入的“交换后身份+加成”覆盖原主公失去加成及原非主公获得加成两方向；这不代表身份交换入口已实现。

## 装备与牌区

`_do_sage_save`先`_discard_all_cards(p, true)`，再复原武将，清自身连环/酒/佩戴暂态并摸四张任意牌。摄魂刀激活、贤者标记随原装备资源保存，按B04实体生命周期清理；不是武将初始状态。破风枪加成、治疗权杖本回合缓存、坐骑距离与暗置索引也不保留旧装备效果。其他角色的装备与武将状态不受复原影响。

## 本批验证与后续入口

`general_state_cases`挂载现有核心套件：七将×原主公/原非主公，验证基础上限+当前身份层、身份公开不回滚、所有登记武将字段、各牌区原对象仅弃一次、四张任意牌、其他玩家及既有次数/授予阶段保留。注入各将不天然拥有的限定/觉醒标记用于检查统一清理，不声称这些组合可在当前合法对局出现。

E02继续审计全局bool与回合/阶段ID、获赠阶段刷新，E03处理异步选择生命周期。E01c `c0cdc8f`已修`_check_awaken_trigger/_on_hand_updated`对非0号的觉醒检查，1～4号任意/具体响应最后手牌及贤者后再觉醒回归通过。0号弹窗与全部用牌/失牌事件的精确优先级仍归E03/F；本表不宣称七将所有能力均已完整验收。

E03c `7ec98dd`将已扣上限/已摸牌标记awaken_effects_applied纳入武将快照，复原后可重新觉醒；awakening_revision是仅递增的异步代次，不入快照。_awaken_in_progress仅记录当前等待，不是游戏效果。三选一等待重开不能重复已结算部分；贤者推进代次后旧答复不得写入新一轮觉醒。人类主动取消/超时默认另待E03-Q1。
