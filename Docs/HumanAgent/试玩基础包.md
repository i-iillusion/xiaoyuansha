# 校园杀源码试玩基础包

这是当前开发原型，不是完整首版或免安装 EXE。需要 **Godot 4.7.2 标准版**；没有网络联机。当前只开放2/3人无身份乱斗和5人经典身份局，你控制玩家0，其余由AI行动。6～10人、奸雄、单位及动态空间留待后续阶段，不从新版手册补齐规则。

## 下载与启动

远端 dev 每次成功 CI 的 Actions 页面提供 `playtest-source` 下载物，ZIP内含 `project.godot`、Scripts、Scenes、Docs、README。下载物以该次运行的提交为准；失败运行不会生成新包，不要把上一次绿灯用于新提交。

解压到一个新目录，用 Godot 4.7.2 的“导入”选择 `project.godot`，等待导入结束，按 **F5运行项目**（主场景是 MainMenu）。包没有导出模板、引擎程序、自动测试、Git历史或用户PDF；开发/回归请克隆完整仓库。

仓库中也可执行 `Test/package_playtest.ps1`，它只打包已提交的 HEAD，不包含工作区草稿；输出位置、完整提交号和 SHA256 会打印出来。若想核验版本，可用 ZIP旁生成的 `source.json`，或者对应 Actions 的提交号；下载包本身只包含该提交的原始文件。

## 第一次试玩

1. 选择“开始游戏”→“测试模式”。切换到自选武将模式，先开2人乱斗熟悉操作，也可开3人乱斗或5人标准身份局。
2. 自选“稻草人”是不带技能的测试占位，对手也为稻草人；稻草人基础5体力，5人身份局主公另加1。随机模式从八名已开放武将无放回分配。
3. 当前八名武将为凯文、布鲁斯、安普提、史蒂芬、杰基、麦克斯、里奥、比尔；选将列表可滚动，名称以菜单显示为准。AI采用保守策略，不保证主动发动所有技能；例如里奥AI不主动更换锦囊，真人合法窗口仍可更换。
4. 到你的出牌阶段，用底部出牌入口选牌，再按提示点击目标、确认。普通摸得的手牌是任意牌，可以声明合法牌；已具体化后流转回手的牌只能按具体名称使用，不能当任意牌。以UI显示的合法选项为准。
5. 多目标、弃牌、闪/杀、救援及技能窗口按屏幕提示处理；强制选择不能用取消逃避。带读条窗口的超时有各自已裁决结果，不能统一理解为同意或随机。
6. 不继续出牌时按“结束出牌”。完整对局结束后按“返回主菜单”，可重新选模式和武将开局。无身份乱斗最后一名存活者胜利，全灭平局。

规则依据是[采用的手册](../Original/校园杀完全知识手册.md)加[现行裁决](现行裁决索引.md)，负责人最新裁决优先。整本新版未启用。未实装资料将和后续模式不是本包承诺范围。

## 仍需人工验收（未执行）

自动测试在无窗口模式走真实菜单按钮信号和场景切换，不能证明鼠标、键盘、画面布局和实际读条体验正常。请试玩者逐项确认：

- [ ] 1280×720及本机实际窗口/DPI下菜单、头像、血条、手牌和提示可读，没有遮挡。
- [ ] 自选列表可滚动至全部八将，技能详情完整；随机入口也可正常开始。
- [ ] 点目标、选牌、取消自愿动作、多目标确认、结束出牌均可正常输入。
- [ ] 带读条响应及强制弃牌可操作；不会显示两个冲突窗口或把旧按钮答复送入新窗口。
- [ ] 实际玩完至少一局，终局只显示一次；返回菜单后重新开局，再玩完一次。
- [ ] 2/3人乱斗和5人身份局分别检查布局、身份显示及胜负提示。
