## 1. 规则来源与已确定范围

依据[现行手册](../Original/校园杀完全知识手册.md)3.1、3.5、3.6、5.1、6.12，及[现行裁决索引](现行裁决索引.md)、H03/I03/I04/I05a/I05b已采纳裁决。新版整本手册未启用。

手册6.12原文：

> 【周苏忆/桑尼·斯派】「腐败的间谍」体力上限：4
>
> 【拍片】出牌阶段，你可以弃置一张手牌，并选择除你以外的两名角色，令他们各回复一点体力。
>
> 【间谍】限定技，出牌阶段，你可以交换场上两名角色的身份直至游戏结束。
>
> 【贪污】当有角色额外摸牌时，你可以与该角色进行一次拼点。若你赢，你获得该角色额外摸的牌；若你输，你翻面；若平局，你可以在以下两项中选择一项：1.只获得他摸到的一张牌。2.继续进行一次拼点。

手册3.5原文：“除摸牌阶段以外的摸牌将视为额外摸牌。”不能擅自改为“超过基础两张的部分”。手册3.1拼点为两名角色；默认平局重猜不覆盖贪污自己的平局分支。

| 范围 | 实施依据与限制 |
| --- | --- |
| 拍片费用 | 一张手牌；任意牌也是合法手牌，不要求具体牌。不接受装备/判定牌代付，不添加每阶段一次限制。 |
| 拍片目标 | 两名互不相同的其他角色；不选自己。未写“已受伤”，不自行增加受伤限制；满血回复按正常上限处理。合法性仍受分区、潜行、角色类别约束，不能把山纳入普通治疗目标。 |
| 拍片回复 | 每人正常回复1，不是使用桃、不额外套桃的加成。彼得免效用现有多目标接口，不因一人免效回退已付费用。 |
| 获赠阶段 | 写明出牌阶段的技能均可在获赠出牌阶段使用，不再询问这条通则。 |
| 间谍目标 | 最新Q1排除当前主公：两名不同、具有身份的存活非主公玩家；发动者若为非主公可以参与交换，主公发动者仍可交换另外两名非主公。不以身份相同过滤目标，否则会泄露暗身份；不能赋予无身份火龙一张身份。 |
| 间谍模式 | 乱斗没有身份相关技能；有身份局才开放。交换身份不等于交换武将，不是一次奸雄声明，也不自动触发忠内转换。 |
| 限定技复原 | 次数属于武将牌状态，接既有贤者复原接口；身份和主公加成仍独立管理。Q1已禁止交换主公，不实施主公HP/加成转移；Q2原主公公开状态局面随之关闭，不添加重新隐藏规则。 |
| 摸牌与移牌 | 获得、顺走、交换原牌不等于摸牌；不能监听所有手牌数量增加来触发贪污。Q4已定：开局发牌不是额外摸牌，不触发贪污。 |
| 摸牌阶段 | 英姿、好田等在本人正常摸牌阶段增加的摸牌不能仅因“多于2张”触发。QA-T324明确：麦克斯赠出的DRAW中受赠者正常摸牌不是额外摸牌；麦克斯发动烂忠厚摸的1张是额外摸牌。须携带摸牌所属阶段与原因，不能只检查全局阶段枚举或当前回合角色。Q5已定：他人在当前角色DRAW期间觉醒摸2仍是额外摸牌，可触发贪污。 |
| 拼点与平局 | 单次猜拳后显式进入贪污平局分支，不调用自动重猜到胜负的普通拼点帮助器；两人拼点不生成自己对自己的窗口。不得让山参与拼点。 |
| 优先级 | 预大习最高优先级不变；其摸牌回调当前为同步接口，迁移时要验证整个死亡栈，不盲目全局改await。 |

## 2. 实现入口审计（基线0e48f0c）

`Scripts/GeneralData.gd`的6.12目前只有metadata、上限4，尚无三技能实现。不得仅凭登记名开放。

### 2.1 身份交换

`Scripts/Player.gd`中identity_max_hp_bonus的setter只改变max_hp，不负责当前HP压限或回血。武将快照捕获排除身份加成，复原再加当前身份加成。不得借由修改general或执行贤者来实现身份交换。

`Scripts/AmbitiousIdentityState.gd`保存`_roles`、`_original_lord`、`_lord`、`_ambitious`；`valid()`逐人比较当前identity和缓存。直接交换两个Player.identity会使有效性校验失败，并使声明/判胜失效。必须审计交换后当前身份与原始开局身份各自用途，增加明确的状态同步入口并回归。若原始身份资格的实际局面出现手册不能判定的分支，另举例询问，不以缓存结构代替规则。

`GameManager._resolve_ambitious_declaration`等待窗口时同时持有candidate、生命周期与阶段revision。交换/复原/断线都必须拒绝旧答复；不把交换当作声明成功。Q1禁止主公参与交换，因此不实现活人主公交换回血或主公加成迁移。H03奸雄继位2/4→3/5保持原裁决。

还需核验PlayerObservation、LanGameBridge和胜负逻辑：仅新公开身份可传给第三方，暗身份始终仅本人可见；不能通过选人按钮、提示、日志或状态摘要泄露未公开角色。事务提交时不要在两个角色更新之间同步半成品。

## 3. 六个审计局面的裁决与关闭记录

以下六题于2026-11-09提出；同日负责人已答复Q1、Q3～Q6。Q2原局面因Q1的禁止条件不再可能发生，标为不适用而非推定另一条公开规则。后续若出现新的实际歧义，继续举合法具体局面并保留“不清楚，需要商议”选项。

### I05-S-Q1：活人主公交换时的HP

五人身份局，A桑尼为主公5/5，B忠臣2/4。A交换自己与B的身份。两人应变为A4/4、B3/5（升主回复1），还是A4/4、B2/5（只加上限）？也可指定其他处理。负责人裁决：“此技能不能替换主公的身份”。本例不合法，不执行交换、不消耗限定次数；身份、体力和上限均保持原状。这里是限制交换目标，不是禁止主公身份的桑尼发动技能交换另外两名非主公。

### I05-S-Q2：原公开主公是否重新隐藏

同局A原主公已公开，B原忠臣未公开；交换后B成为主公公开。A的忠臣身份重新隐藏，还是仍公开？Q1已禁止该交换，本例不再适用，不再等待本题单独答复；不实现主公退位或重新隐藏。其他公开身份交换情形不由本例推定。

### I05-S-Q3：贪污拿牌是否经过原接收者手牌

B大卫在出牌阶段因五谷将摸2张，A桑尼确认贪污且拼点赢。是B先获得2张后A取走，还是直接进入A手牌、B从未获得/失去？负责人裁决：先进入B手牌，再由A获得。不能把B从未获得/失去牌当实现；保留真实失牌时点，与既有摔角入口一并验收。

### I05-S-Q4：初始发牌

五人开局有A桑尼，每人初始发4张任意牌。B的初始4张是否触发贪污？负责人裁决：不触发，开局发牌不算额外摸牌。初始化复用draw帮助器也必须显式排除。

### I05-S-Q5：他人在当前角色摸牌阶段觉醒

A克里斯在自己的DRAW偷走B史蒂芬最后一张手牌，B立即觉醒摸2；C桑尼与B同区。C是否可对B这2张发动贪污？负责人裁决：算额外摸牌，可以触发贪污。区分当前角色A的DRAW与B自己的摸牌阶段；不能用全局current_phase == DRAW一刀切排除。

### I05-S-Q6：拼点平局后选择超时

B额外摸2张，桑尼已确认贪污并单次猜拳平局。窗口提供“拿其中1张”与“继续拼点”，桑尼直到基础读条耗尽都未选。是默认拿1张、放弃本次不拿牌不再拼点，还是其他处理？负责人裁决：默认获得其中1张。不能超时自动继续拼点，也不能自动放弃拿牌；本题未另行规定当批次有多张时具体拿哪一张，不把这条默认分支自行扩成固定牌位或随机策略。
