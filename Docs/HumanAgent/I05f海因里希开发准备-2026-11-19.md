# I05f 海因里希·迷因开发准备

I05e 已在 `664fb7e` 完成。按《开发执行计划》第 9 节，组 A 下一位是手册 6.21 的海因里希·迷因，基础体力上限 4。先完成可分别验收的技能，再接 AI、联机和独立开放候选。

| 顺序 | 范围 | 入口与验收 |
| --- | --- | --- |
| I05f-1 | 【恐同】对比尔【同性恋】的目标免疫 | 从 `GameManager._gay_target_valid` 开始，核查实际付款前及结算前的复验，房主和远端都不能选择海因里希。用同区、同性、受伤且原本可选的海因里希作反例，用普通玩家作正对照。 |
| I05f-2 | 空武器槽对同性目标使用杀的后效 | 核查 `_prepare_strike_target` 和 `_resolve_chixiong` 能否复用既有弃一张或令来源摸一张的窗口。分别验真武器、暗置武器、无性别单位、青釭盾、改目标、装备变化、放弃及技术失效。缺少裁决的交互先隔离。 |
| I05f-3 | 【玩烂梗】计数与响应 | 用 `CardActionEvent` 的原卡、声明牌名、实际行为主体与真实回合标识核对 USE、RESPONSE、虚拟响应和预习换牌。把计数、询问、伤害和第三次发动的后效分开验。重复窗口和失效后的后续牌须有对照。 |
| I05f-4 | 南蛮／万箭额外次数 | 核查 `TurnManager.can_use/use_card` 及群体锦囊、预习改牌的入口。手册只额外允许一张南蛮或万箭。测试由其中任意一种使用额外次数，并检查赠阶段、AI 和真人菜单一致。 |
| I05f-5 | 组合、复原、AI、联机和开放 | 测公开状态、贤者复原、来源死亡后续接、错座和旧令牌。隔离候选通过正常大厅选将、真实付牌、回归与联机门禁后再登记开放。 |

手册 6.21 没有写明下面三种边界。进入受影响的实现前按实际场景裁定，I05f-1 可先做。

1. 同一回合依次打出四张杀，第三张触发后已发动。第四张是否再次提供机会，还是同名牌每凑满三张才有下一次机会？若第三张时放弃，第四张是否提供机会？
2. 同一回合依次打出普通杀、火杀和雷杀。这三张合计为三张相同的牌，还是按具体牌名分别计？双闪等响应的实体支付仍逐张可追踪。
3. 【玩烂梗】第三次确认发动时，原文连续两次写了“可以对除你以外的所有角色造成一点伤害”。第三次是额外再询问一次、自动结算第二轮，还是只结算原来的一轮？若是两轮，需确认逐人顺序以及第一轮中途来源死亡后的第二轮。

上述问题可答“我也不清楚，需要商议”。另在 I05f-2 审核是否需要为【恐同】单独明确超时和防具交互。现行索引中没有这两项专属裁决，不能直接把雌雄双股剑的全部规则套给技能。
