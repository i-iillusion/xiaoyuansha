## 启动与连接

1. 所有人解压同一个ZIP，运行`CampusSha-LAN.exe`，无需安装Godot。
2. 进入“开始游戏 → 多人游戏 · 局域网”。一人输入昵称、选择2/3人乱斗或5人经典身份局，点击“创建房间”。
3. 房主把界面列出的局域网IP发给同伴；其他电脑填写该IP、相同UDP端口（默认24567），点击“加入房间”。`127.0.0.1`仅供同一台电脑多开。
4. 各自选将并准备，人数齐全后由房主开始。非稻草人武将不能重复；随机选将自动避重。

请仅在信任的局域网或经授权的虚拟局域网使用。Windows询问网络权限时，仅授权你信任的网络；不要关闭整个防火墙，不需要公网映射。同一Wi-Fi的访客隔离、不同网段或VPN可能阻止连接。端口被占用时，可由全员改用相同新端口（1024～65535）。当前没有房间发现或密码、掉线重连、互联网匹配。

此内部原型没有代码签名；不建议向不信任来源的程序授予权限。应通过负责人提供的ZIP及SHA256确认来源。

## 跨城市：先用虚拟局域网

不同城市不必处于同一个Wi-Fi：让各电脑加入同一个私有虚拟网络，再把游戏中的房主IP换成该工具分配给房主的IPv4即可。菜单仍叫“局域网”，游戏程序无需修改。不要填写家中192.168地址、127.0.0.1、网络ID或网页链接；连接框目前需要IP地址，不支持域名。

### 推荐试玩路线：ZeroTier

1. 房主在 https://www.zerotier.com/ 注册自己的账户、创建一个私有网络。保留成员逐个授权，不设为公开网络。
2. 每位成员从官网安装ZeroTier，在客户端用同一个Network ID加入网络。房主在管理页面核对各成员设备ID并授权，只批准约好的电脑；不要共享管理账户密码或API密钥。
3. 确认每台电脑在线且获得虚拟IPv4。房主把自己的虚拟IPv4发给同伴，保持ZeroTier运行。
4. 房主运行本游戏创建房间；同伴填房主的虚拟IPv4和24567加入。先用两台异地电脑开2人局验证，再邀请五人测试身份局。
5. 结束后可退出虚拟网络或撤销成员设备授权。不要为此开启家庭网段路由、默认路由或文件共享。

官方逐步说明：https://docs.zerotier.com/start/ 。2026-10-08核对的Personal免费方案为个人非商业使用、10台设备、1个网络、1名管理员，以 https://www.zerotier.com/pricing/ 实际条款为准。这是工具额度，不意味着本游戏已经开放10人局。

### 备选：Tailscale

各成员安装官方客户端，通过房主邀请加入同一个tailnet（各用自己的账户，不共享登录），填房主的Tailscale IPv4连接游戏。无需开启出口节点或子网路由。官方邀请说明：https://tailscale.com/docs/features/sharing/how-to/invite-any-user 。当前Personal免费方案最多6位用户，可覆盖当前5人试玩，见 https://tailscale.com/pricing 。直连受阻时可以使用中继，但真实运营商/跨城延迟和服务可达性需要你们实测，不能保证所有网络均能连接。连接方式：https://tailscale.com/docs/reference/connection-types 。

### 连不上时按顺序排查

- 全员使用同一个游戏ZIP；房主已建房、人数未满、尚未开始对局。
- 虚拟网络中设备已授权且在线，填写的是房主的虚拟IPv4，端口一致。房主需始终在线，不能睡眠。
- 检查虚拟网络访问策略允许成员到房主的UDP 24567；Windows防火墙仅为本EXE、该UDP端口、虚拟网卡及已知成员虚拟IP设置所需入站权限。不关闭防火墙，也不把所有网络统一改为“私有”。虚拟网卡被归为公用网络时，单纯勾选私有网络可能不够，应按实际网卡配置精确规则。
- 网络工具显示在线不等于游戏UDP可达；ping失败也不一定说明游戏不可达。Windows的Test-NetConnection端口测试是TCP，不能用它证明本游戏UDP端口通畅。
- 仍失败时记录客户端提示、双方工具连接状态、包版本及运营商；可换另一位成员当房主。不要直接把无密码的游戏端口映射到公网作为排障办法。

虚拟网络会建立设备间网络通道，只加入专门给试玩使用且成员可信的网络。游戏没有公网级认证和防滥用能力；不要公开转发24567，也不要把房间直接部署成公开服务。本次没有自动安装网络工具、改系统防火墙或创建任何云端账户。

### 如果希望只发EXE、不安装网络工具

需要另做公网服务版，而不只是改一个IP：部署可达服务器，补房间码/授权、加密连接、输入大小与频率限制、服务端房间隔离和断线处理，再做两地真实网络验收。现有房主权威结算和座位校验可复用；无额外安装的中转或专用服务器尚未实现。选这条路线前需确认可用服务器、预算和部署地区，本包不承诺支持。

## 对局操作

界面以1280×720为基准随窗口等比例缩放，4K下文字和控件一起放大；最小窗口960×540。非16:9窗口可能有留边，用于保持界面比例。新版试玩修复了最大化后字体仍很小的问题；所有成员请统一换用同一个新版ZIP。

- 顶部显示自己的身份、手牌与当前读条。其他玩家只公开手牌数量、公开身份及场上信息。
- 普通五人桌面的左下角和本人的详情也显示自身身份；查看自身身份不会将其公开。其他角色未公开身份的问号统一灰色，不以文字或颜色透露具体身份。
- 轮到你时点“出牌”，按分类选择卡牌；点击角色卡选择目标，并完成确认。点击自己的角色卡可以查看/使用已实现的主动技能。
- 需要你响应时，下方显示该响应的真实选项；多选弃牌先勾选再确认。其他人的操作窗口不会显示给你。
- 暗置牌只显示已公开类别，不会通过联机广播其未声明名称。普通摸牌仍为任意牌，具体化牌保持原名。
- 联机采用简化的文字操作面板；悬停按钮可看装备/技能/卡牌描述。较长窗口向下滚动。没有新增美术。
- 非当前行动者的合法“下跪/解除下跪”会显示独立按钮。
- 终局后，房主点击“返回房间，再开一局”，所有人重新准备。

## 当前边界

仅含当前已实现的八名武将及稻草人占位，2/3人乱斗、5人身份局；不开放6～10人、奸雄、未实装召唤单位等后续模块。联机全部座位由真人控制，无AI补位。

房主或任一成员断开会中断当前对局，不据此判胜、不托管或恢复旧局。房主尚在时，补齐人数并重新准备；房主退出则需重新建房。此包用于内部规则/交互验证，不能保证所有武将组合无缺陷。

## 请成员重点实测

- [ ] 至少两台电脑实际连接，核对Windows私有网络权限。
- [ ] 两个城市通过同一私有虚拟网络连接，完整对局并返回房间；记录延迟、断线及重开表现。
- [ ] 各座位只能看见自己的身份、手牌及自己的响应窗口。
- [ ] 出牌、猜拳、救援、强制弃牌、具体牌和暗置装备可操作，长列表可滚动。
- [ ] 5人身份局与2/3人乱斗各完整试玩一局，终局返回并重开。
- [ ] 断开一名玩家/关闭房主后有明确中断提示，无自动判胜。

自动化连接和规则回归不等于上述跨电脑/视觉人工测试已经通过。
