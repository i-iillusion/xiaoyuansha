# 回合、阶段与事件计数登记

2026-10-06新增待实施计数CARD-04：借刀要求的出杀按第一目标分别计入“当前回合内借刀出杀次数”，与其普通主动杀计数互相独立；上限使用其既有出杀能力（一般1、连弩2、诸葛连弩不限等）。工程计划按turn_id/第一目标单列计数，实际当前回合切换才清零，不每张借刀/WAITING/获赠阶段刷新。必须增加原A回合用满、B回合从0及正常主动杀不互占的正反回归；目前没有此字段，不称已迁移，不把南蛮/决斗响应也纳入它。

## E02a 已迁移

`TurnManager.turn_id`在`start_game/next_turn → _begin_turn`递增，清全部角色的本回合用牌历史。`phase_id`在实际进入规则阶段时递增；进入WAITING及从WAITING返回PLAY保留同一规则阶段。交互`_context_revision`仍独立递增，旧异步答复不能因规则阶段ID相同而复用。直接给current_phase赋值只是测试/内部状态操作，正式阶段事件仍用_change_phase。

| 计数 | 增加入口 | 归属/清除入口 | 说明 |
| --- | --- | --- | --- |
| 主动杀`strike_count_this_turn` | `use_strike` | 实际出牌操作者、本回合；`_begin_turn`统一清 | 响应打出不占主动额度；连弩等只改变上限 |
| 决斗`duel_count_this_turn` | `use_card("duel")` | 同上 | 每人每回合2；霸王查询额度3 |
| 南蛮/万箭`aoe_count_this_turn` | `use_card("aoe")` | 同上 | 共用2次 |
| 拆/顺`steal_count_this_turn` | `use_card("steal")` | 同上 | 共用2次 |
| 桃园、五谷、卸甲各自计数 | 对应`use_card` | 同上 | 各1次，不因新出牌阶段刷新 |
| 青龙首次使用/打出杀`_strike_actors_this_turn` | `_record_strike_played → record_strike_played(seat)` | 每座位、本回合；`_begin_turn`清 | 与装备是否在场、主动杀次数分开；响应/更换装备不清 |

上述旧字段保留为当前实际操作者的兼容查询/赋值接口，底层为`_turn_card_counts[seat][kind]`。获赠者不会读到回合主人的次数；返回原操作者读回其已有记录。移除DRAW结束时的清零，避免抹去本回合前段已经发生的事件。重开同时清旧等待、跳阶段及赠送目标；不清任何未来轮限技能。

`turn_counter_cases`挂载核心套件，覆盖规则阶段/交互代次区别、跨阶段历史、操作者独立限额、返回原操作者、下一回合与重开。实际共同出牌入口另覆盖两个操作者各一次卸甲支付/原装备入弃，第二张拒绝且不扣手牌。青龙实体触发及赠送实际AI/真人出牌入口由既有核心案例继续回归；本批不把手工切换操作者测试称为完整额外阶段调度。

## E02b 已迁移

`_phase_skill_uses[skill][seat]`保存最近使用/禁用的phase_id。Gay、没用、装逼旧bool接口读取实际操作者；新阶段自动失效，响应返回保持。没用支付后立即登记，不在暗置声明等待后再写；Gay/没用选项等待失效不扣费。实际获赠阶段响应返回继续使用play_actor_idx。

## E02c 已迁移

主动酒次数`wine_count_this_turn`加入按操作者的回合历史，`play_card(WINE)`真实支付成功才增加。`can_play_wine`由声明/实际出牌共用，普通每回合1次、战斧无次数上限；战斧期间仍计历史，失去战斧不返额度。出杀消费的是加伤层数，濒死自救既不加层也不计主动酒次数；新回合才清历史。
