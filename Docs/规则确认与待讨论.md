# 规则确认与开发边界

更新：2026-09-07。依据：根目录《校园杀完全知识手册 初版 V2.pdf》及项目负责人本次逐条答复。美术资源不在本轮范围内。

## 使用原则

知识手册为规则正文；负责人明确补充的裁定覆盖相应旧文字。未覆盖的基础规则可参考经典身份局及军争基础规则，但不能用其他版本填补本项目明确标为“待讨论”的条目。记录为已确认不代表代码全部实现。

## 本轮确认的结算方式

四个主要时机：指定目标、成为目标、造成伤害、受到伤害。普通伤害暂按以下内部顺序实现：

指定目标 → 成为目标 → 响应 → 造成伤害前 → 受到伤害前 → 提交体力变化 → 濒死/死亡 → 普通伤害后技能。

- A 对 B 使用【杀】，C 在 B 成为目标时打出【舍己为人】；随后 C 成为目标，可以正常出【闪】。未闪避时，A 可发动【丈八蛇矛】，伤害按 C 的防具和状态结算，不沿用 B 的减伤。
- 【丈八蛇矛】在命中后、实际扣血前支付流失体力，基础伤害和加成作为一次伤害处理，防具只修正一次。“爆3血”的聊天例子不单独定义新的伤害数值公式。
- 使用统一伤害记录，保留原始来源、当前来源、原目标、实际目标、属性、伤害量及是否传导，避免目标变化后重复加伤/减伤。
- 体力保留实际值，包括负数和特殊效果造成的超上限体力；普通回复仍不超过体力上限。濒死不等于死亡，来源完成死亡结算后，剩余伤害变为无来源。
- 单独规则可暂停普通链条，处理完后回到原阶段。【预大习】优先于普通时机，但其未决细节不因调度接口存在而视为已经确定。
- “无论是否合法”暂只越过选目标限制（例如距离、性别、不能成为目标）；不免除费用，不禁止目标响应，也不取消伤害免疫。普通信徒行为仍须合法。
- “穿过”指圆桌上连线；这只确定几何解释，没有确定山与地雷的全部判定细节。
- 【贤者的加护】完全复原武将牌的开局状态，包括被改动的体力上限、觉醒、界限突破、获得/失去的技能及限定技状态。旧牌全部弃置后摸四张，而非把开局手牌重新发回。

## 明确保留待讨论

- 主动替换装备是否触发“失去装备”（原第 23 项）。
- 【装傻】平局是否重新猜拳（原第 25 项）。
- 一轮在额外回合、跳过回合、死亡以及召唤单位参与时的边界。
- 地雷的放置、触发、归属及清理等细节；山的几何边界、遮挡范围与交互细节。
- 火龙之外的召唤单位是否计入角色数、召唤者死亡后是否消失。
- 单独规则的竞争及【预大习】完整结算细节。调度器的同优先级先进先出只是程序机制，不是多人同时发动技能的规则裁定。
- 前轮其他已标记待讨论且尚未得到明确答复的技能组合，不因本轮普通伤害顺序被采纳而自动确定。

提出新问题时应保留“我也不清楚，需要与其他人商议”选项；不得把程序默认行为写成已经确认的线下规则。

## 本次实现范围与仍需材料

本次接入了杀、普通伤害、连环伤害共用的伤害链；修正杀的代受时机、丈八/防具单次结算、贤者对现有武将状态的开局复原、两种劣马的受伤后转移。提供真实体力与明确死亡状态，以及结算边界的高优先级异步规则接口。

注意：旧代码的 `is_alive()` 暂保留“可行动”的含义；判断是否完成死亡必须使用 `is_dead()`，判断是否还在救援窗口使用 `is_dying()`。新武将的状态字段需要登记到开局快照中，不能遗漏。

后续继续工作时已补上：【装逼】胜负各半后的本阶段禁用、【火烧连营】先入判定区、【卸甲归田】每回合一次，并增加独立回归测试。

尚未实现所有手册武将、界限突破系统、信徒系统及【预大习】完整效果；“无论是否合法”目前为杀结算提供内部开关。装备具体牌实例的全部移动路径、苕的抢先声明及烈火盾技能费用等仍需逐项审计。本轮没有修改待讨论的装备替换触发或装傻平局处理，也没有制作美术资源。
